# Project 1: Enterprise Cybersecurity Home Lab

## Objective
Build an isolated enterprise cybersecurity environment
using VMware Workstation Pro, Windows Server, and Linux.

## Technologies
- VMware Workstation Pro
- Windows Server
- Active Directory
- Windows 11
- Ubuntu Linux

## Project Status
Not Started

## Goals
1. Configure an isolated virtual network.
2. Deploy Windows Server.
3. Install Active Directory.
4. Create an enterprise domain.
5. Deploy a Windows 11 workstation.
6. Join the workstation to the domain.
7. Document the architecture and configuration.
